Here is a Monty Hall paradox simulator to experiment the un-understood 1/3-2/3 solution instead of the 1/2-1/2.

You can play the programm only in a terminal for now but graphical interface will come soon.
2 modes are availables :
- Manual, you choose manualy
- Automatic : You choose a number of parties, your stratégie and the programme play the game alone.

Results : You can see hom many times you win and how many times you loose and the percentage of win.
